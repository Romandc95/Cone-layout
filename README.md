# Cone Layout

Flat-pattern calculator for concentric cones and reducers. Enter large Ø, small Ø and takeoff; get trammel radii, arc angle, a baseline offset station table, and tape checks (side length, diagonals, arc lengths). Layout is figured on the mean diameter so thin-gauge stainless closes after rolling.

Live: https://romandc95.github.io/Cone-layout/
